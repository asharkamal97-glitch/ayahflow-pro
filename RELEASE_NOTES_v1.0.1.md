# AyahFlow 1.0.1 — Mobile UI Redesign & Audio Recovery

Official production release of AyahFlow Pro for Android and Web.

## What's New in v1.0.1

### 🎧 Dedicated Mobile Listening Experience
- **Dedicated Native Mobile Interface:** Running the installed Android app now presents a focused, serene Quran listening sanctuary.
- **5-Tab Mobile Navigation:** Direct access to Home (Listening Sanctuary), Surahs (Browse & Search), Playlists (Curated Collections), Ambient (1-tap Atmosphere Mixer), and Settings.
- **Clean App Isolation:** Removed all website marketing hero sections, download prompts, and installation guides from inside the installed app.
- **Enhanced Safe Area Support:** Coordinated floating MiniPlayer dock and navigation bar spacing with Android system gesture bars and status bar.

### 🔊 Audio Engine & Playback Fixes
- **Accurate Audio Timeline:** Restored real-time duration and elapsed time display; resolved transient metadata reset bugs.
- **Fluid Seeking & Scrubbing:** Added smooth ±10-second forward/backward skip controls and responsive touch scrubbing across all player views.
- **Sequential Playlists:** Natural automatic track transitions for curated playlists (Focus & Work, Deep Sleep, etc.) with repeat mode support.
- **Natural Next-Surah Advancement:** Continuous recitation across Surahs (1 -> 114) upon natural completion without accidental skips.
- **Ambient Soundspace Isolation:** Completely isolated secondary atmospheric loop elements, eliminating empty audio source warnings.
